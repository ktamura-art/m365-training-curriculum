# 全社内製化プログラム｜カリキュラム管理画面

Microsoft 365 の内製化研修（全10回：共通7回＋高レベル グループ別3回）のカリキュラムを、検討・選定しやすい形にした閲覧用の管理画面です。

主軸：Power Automate ／ Power BI　　補足：SharePoint リスト（Power Automate の転記先・Power BI の入力元として必要な範囲）　　第7回：AI Builder ／ エージェントビルダー ／ Copilot Studio

## 画面構成

| タブ | 内容 |
|---|---|
| 全体カリキュラム | 全10回・69項目・469機能。先頭に「主軸と補足」の構成。各項目に「扱う機能」と受講レベル（低＝全員／中＝補講・強化／高＝業務別グループ）を明示。レベル・ツール・機能名で絞り込み |
| レベル分け（低・中・高） | 3レベルの目標・例・受講する回、高レベルの3グループ（問合せ対応 AI／複数システム連携／RPA×Power Automate）、回とレベルの対応表 |
| 機能一覧（網羅チェック） | 415機能を製品別に一覧。扱い方（演習／デモ／講義）と該当回つき。機能名で検索可 |
| やりたいこと逆引き | 「これができるようになりたい」から該当回と実現度を引く |
| 運営・前提・ライセンス | チーム編成・到達指標・前提事項・ライセンスの境界 |

## 構成

- `index.html` — 画面（依存ライブラリなし）
- `data.js` — カリキュラム定義（回 → 項目 → 扱う機能 の3階層）。ここだけ編集すれば内容を差し替えられます

ローカルで開く場合は、`data.js` を読み込むため簡易サーバー経由で表示してください。

```bash
python3 -m http.server 8000
```
