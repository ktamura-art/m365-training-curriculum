# 全社内製化プログラム｜カリキュラム管理画面

Microsoft 365 の内製化研修（全8回）のカリキュラムを、検討・選定しやすい形にした閲覧用の管理画面です。

対象ツール：Power Automate ／ SharePoint リスト ／ Power BI ／ Copilot Studio ／ エージェントビルダー ／ AI Builder

## 画面構成

| タブ | 内容 |
|---|---|
| 全体カリキュラム | 全8回・48項目。レベル・ツール・キーワードで絞り込み |
| ツール別 | どのツールがどの回で何分を占めるかの分解 |
| レベル分け | L1 知る／L2 作る／L3 回す の3段階 |
| やりたいこと逆引き | 「これができるようになりたい」から該当回と実現度を引く |
| 運営・前提・ライセンス | チーム編成・到達指標・前提事項・ライセンスの境界 |

## 構成

- `index.html` — 画面（依存ライブラリなし）
- `data.js` — カリキュラム定義。ここだけ編集すれば内容を差し替えられます

ローカルで開く場合は、`data.js` を読み込むため簡易サーバー経由で表示してください。

```bash
python3 -m http.server 8000
```
